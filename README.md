## 🚀 Запуск

Склонируйте репозиторий:

```bash
git clone https://github.com/yudix10/JavaScript.git
```

Перейдите в папку проекта:

```bash
cd JavaScript
```

JavaScript-файлы можно запускать в браузере или через Node.js в зависимости от конкретного задания.
