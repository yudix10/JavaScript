Задание. Для каждой из задач ниже создать массив, состоящий из случайных значений (заполнить массив, используя функцию random()). Весь процесс решения задачи оформить в виде функции.

1. Задан целочисленный массив, состоящий из n элементов, расположенных в диапазоне [-10;10]. Найти количество элементов, абсолютное значение которых больше среднего арифметического массива. (При решении задачи использовать методы filter() и reduce(). Количество элементов вводится с клавиатуры).

2. Cоздает одномерный массив, заполнить его произвольными числами в диапазоне [-50;50].  Затем для каждого элемента массива вывести следующую информацию: «Элемент … - четный (нечетный) положительный (отрицательный)» (При решении задачи использовать метод ForEach()).

3. Задан целочисленный массив, состоящий из n элементов, расположенных в диапазоне [10;99]. Составить массив, элементами которого будут значения, являющиеся суммой цифр элементов исходного массива. Вычислить сумму элементов полученного массива. (При решении задачи использовать методы map() и reduce(). Количество элементов вводится с клавиатуры).

4. Даны два массива случайных целых чисел по n элементов в каждом. Заменить нулями те элементы первого массива, которые есть во втором. (Диапазон случайных чисел выбирайте самостоятельно. Количество элементов вводится с клавиатуры).

5. Задан массив, состоящий из n случайных целых чисел. Определить, образуют ли значения его элементов арифметическую прогрессию. Если "да" - вывести разность прогрессии, если "нет" - ответ "не образуют". (Диапазон случайных чисел выбирайте самостоятельно. Количество элементов вводится с клавиатуры).
